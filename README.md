# 產線風速風場模擬觀測器

模擬熱發泡（TIJ）噴碼設備在移動箱子上方 **3~5mm** 處噴印時，間隙內的氣流場，
以及 **300 顆墨滴**各自的飄移方向與落點誤差。

固定安裝的噴頭與高速通過的箱子之間只有幾毫米間隙，箱子拖曳並擠壓其中的空氣，
形成明顯的氣流場。墨滴飛越這道間隙只需約 0.5 ms，卻足以被帶偏到影響噴印品質。
這個工具讓你直接觀察「間隙裡到底發生什麼事」。

---

## 主要結論（預設條件：350 m/min、4mm 間隙、30 pL、箱間距 40cm）

| 量測 | 數值 |
|---|---|
| 間隙平均風速 | **2.92 m/s** （= 產線速度的一半） |
| 縱向飄移 Δx | **+135.8 µm** |
| 橫向飄移 Δy | **0（陣列中央）~ ±20.4 µm（兩端）** |
| 合成飄移 | **136 µm = 1.62 個點距** @ 300 dpi |
| 飄移方向扇形 | 兩端各偏 **8.5°**，全幅 17.1° |
| 噴印帶橫向拉伸 | **0.161%**（25.3mm 帶寬總增寬 40.8 µm） |
| 前緣撞擊尖峰 | **146.7 µm = 1.73 個點距**（高於箱下穩態 133 µm） |
| 擾動循環頻率 | **6.48 Hz**（箱長 50cm + 間距 40cm） |

飄移量達 1.6 個點距，是真實且顯著的印刷品質問題 —— 對應實務上觀察到的
「**字歪斜 / 邊緣模糊**」。

程式化使用：

```python
from sim import SimParams, BeltKinematics, WindField
from sim.simulate import fire_burst, steady_fire_time

p = SimParams(belt_speed_m_min=350, gap_mm=4, droplet_pl=30)
belt = BeltKinematics(p)
wind = WindField(p, belt)

r = fire_burst(p, t_fire=steady_fire_time(p), belt=belt, wind=wind)
print(r.summary())
print(r.drift_y_um)          # 300 顆墨滴各自的橫向飄移 (µm)
print(r.drift_in_dot_pitches)
```

## 物理模型

簡化解析模型（非 Navier-Stokes 網格求解），可即時互動。
`Re_h = U·h/ν ≈ 1550` 屬 Couette 主導的過渡區，解析模型站得住腳。

### 風場：週期循環 + 四分量疊加

箱子連續不間斷（間隔 30~50cm），風場是週期性的四階段循環：

1. **開放區** — 噴頭下方無箱，50cm 空曠 → Couette 消失，只剩前一箱尾流
2. **前緣撞擊** — 空氣被活塞式推擠，最劇烈的暫態脈衝
3. **拘束間隙** — 穩態 Couette 剪切 + 擠壓膜逸流
4. **後緣脫離** — 尾流回吸、負壓

```
ux = c·U·(1−ζ)                          Couette 剪切（階段 3 主導）
   + A_edge(t,x)·6ζ(1−ζ)                前/後緣壓差脈衝（Poiseuille 型）
   + (1−c)·wake·(1−ζ)                   箱間開放區的尾流回流
uy = B(t)·sgn(η)|η|^p·6ζ(1−ζ)           橫向擠壓膜逸流
uz = C_v·U·env·[c·6ζ(1−ζ) + (1−c)(1−ζ)] 前緣抬升 / 後緣下沉
```

`ζ = z/h`、`η = (y − y_板心)/L_y`、`c` = 拘束因子。

**邊界條件嚴格成立**：噴嘴板是固定實體壁面，**不論下方有無箱子**，
`z=h` 的 no-slip 與不可穿透在循環的每個相位都為零（有測試釘住）。
拘束時 `ux(z=0)=U`（箱面帶著空氣走）。所有分量都正比於 `U`，
故產線停止時全場為零。

### 為什麼 300 顆墨滴會呈「外八」

關鍵在於橫向逸流的特徵長度是 **噴嘴板半長 12.7mm**，而不是箱半寬 250mm。

噴嘴板是塊**小平板**（約 25mm × 15mm），空氣從底下被擠出時往四面八方逸散，
側向只需走 12.7mm。陣列**中央**的空氣逸出路徑最長 → 橫向速度 ≈ 0；
陣列**兩端**緊鄰逸出口 → 明顯外流。於是 300 顆墨滴呈現對稱的外八圖樣。

> 注意：300 噴嘴集中在 1 吋內，只佔箱寬的 5%，距箱緣超過 230mm，
> 因此**箱緣**（±250mm）的邊界逸流傳不到陣列，未納入模型。
> 已確認的配置是噴頭對準箱子中線。若日後改成噴頭大幅偏向箱緣安裝，此模型需擴充。

### 墨滴：完整彈道 + Schiller-Naumann 阻力

```
鬆弛時間 τ = ρ_ink·d²/(18μ) ≈ 4.8 ms   (30 pL → 直徑 38.6 µm)
飛行時間 t_f ≈ 0.57 ms
Stokes 數 St = τ/t_f ≈ 9.6  >> 1
```

墨滴**來不及跟隨氣流**，只部分響應。若簡化成「瞬間跟隨氣流」會高估飄移數倍
（模擬顯示實際位移 < 完全跟隨的 50%）。這也解釋了為何 10 pL 小墨滴比
50 pL 大墨滴飄得更多。

阻力用 Schiller-Naumann 修正，因為 `Re_p ≈ 10` 已超出純 Stokes（Re<1）適用範圍：

```
F_drag = 3πμd·(1 + 0.15·Re^0.687)·(u_air − v)
```

此形式等價於 `½ρC_d A|u_rel|u_rel`（有測試驗證代數等價），但**沒有 Re→0 的奇異點**。
積分用 RK4、`dt = 1 µs`，對 300 顆墨滴向量化，落點以線性內插求精確值。

### 飄移誤差的基準

飛行期間箱子已移動 **2.9 mm**，遠大於風場飄移的 0.14 mm。這 2.9mm 實務上由
噴發時序補償掉，不能算成誤差。正確定義是：

```
飄移誤差 Δ = 有風落點(箱座標) − 無風標稱落點(箱座標)
```

兩者都換算到箱子座標系，共同的箱體位移自然相消。
**但 Δ 隨產線速度變化，固定的時序補償無法在全速域內修正 —— 這正是實務痛點。**

### 箱重的作用

**箱重對空氣動力學沒有直接影響** —— 風場由速度與幾何決定，不由質量決定。
模型讓質量透過三條真實的機械路徑進入：

1. **驅動力有限** — `a_belt = F_drive/(m_belt + m_box)`，箱越重整線加速越慢
2. **摩擦極限** — 箱子最大加速度 `μg`，超過即打滑落後皮帶
   （純庫倫摩擦下質量相消，故質量是透過路徑 1 才產生差異：
   輕箱皮帶衝得快→箱子跟不上而打滑；重箱皮帶本身慢→不打滑但整體更慢達速）
3. **箱體跳動** — 振幅 ∝ 1/m 調變間隙 `h(t)`，而 Couette ∝ 1/h、壓差 ∝ 1/h²

實測：5kg 箱打滑達 178 m/min；50kg 箱不打滑但達速慢 0.4 秒。

### 未量測、採合理預設值的項目

以下四項尚未取得實機數據，全部設為可調參數，量到實際值直接填入即可：

- **噴嘴板 X 向寬度**（預設 15mm）— 指墨匣底部正對箱子、隔著間隙的**整片平面**，
  不是噴孔直徑（噴孔僅 20~30 µm，對氣流拘束毫無作用）。決定擠壓膜拘束範圍與前緣脈衝強度。
- **噴印帶高度**（預設 1 吋）— 若實機是 1/2 吋（600 dpi），點距減半為 42.3 µm，
  **同樣 136 µm 的飄移就變成 3.2 個點距而非 1.6 個，嚴重度加倍**。可用 `--print-height 0.5` 切換比較。
- **箱子尺寸**（預設 50cm 立方）
- **校正係數** `c_leading`、`sigma_edge_mm`、`c_lateral` 等 — 目前是物理上合理的預設值。
  若有「某速度下的實際偏移量測」，可反推校正，讓模擬從趨勢正確提升為數值貼近實機。

## 次要診斷：X 方向解析度

在 350 m/min 下，要讓 X 向也達到 300 dpi 需要 **68.9 kHz** 噴發頻率，
遠超過 TIJ 的 12~15 kHz 上限。以 15 kHz 計，X 向點距 389 µm（約 65 dpi），
與 Y 向 300 dpi 相差 4.6 倍。

這**不是**目前的主要問題 —— 噴發頻率不足會造成「字被拉長 / 點變稀疏」，
而實際回報的症狀是「字歪斜 / 邊緣模糊」，屬於風場飄移。模擬器同時顯示兩者，
方便日後區分劣化來源。

## 專案結構

```
sim/
  config.py      參數 dataclass + 範圍驗證 + 單位換算 + 診斷量
  belt.py        皮帶啟停、質量耦合、連續箱列相位、拘束因子、間隙調變
  windfield.py   四分量風場 + 週期循環；velocity_at() 向量化查詢
  droplet.py     Schiller-Naumann 阻力、RK4 向量化積分器、精確落點內插
  simulate.py    噴發編排、飄移誤差基準、循環掃描、參數掃描
  plots.py       matplotlib 圖表輸出
  cli.py         指令列入口
tests/           97 項測試：邊界條件、解析極限、代數等價、收斂性、物理趨勢
```
