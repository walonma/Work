# 手機支架（附電扇夾板＋筆電線收納）

桌上型手機支架：鈑金底座加配重，左側有給夾式電扇夾的夾板，中間是可升降、可調仰角、可轉橫放的手機夾，右側是 USB-C 捲線器，附線頭停靠口和充電頭收納槽。

| 項目 | 規格 |
| --- | --- |
| 適用手機 | 一般直板機，寬 60–95 mm、厚度含殼 ≤ 14 mm（彈簧夾爪自動夾緊） |
| 高度調整 | 行程 80 mm，轉軸高度 215–295 mm（160 mm 手機直放時，中心高度約 214–294 mm） |
| 仰角 | 0–70° 往後仰，M6 旋鈕鎖緊 |
| 直／橫 | 托架可轉 ±90°，直放和橫放都可以 |
| 電扇夾板 | 厚 18 mm（電扇夾口最大 30 mm），夾持面 79 × 100 mm，離桌面高 110 mm |
| 捲線 | 90 cm USB-C 線繞在橢圓線柱上（約 5 圈），上方有 USB-C 停靠口，可卡住線頭 |
| 充電頭槽 | 內部 54 × 34 × 40 mm（以 65 W GaN 約 50 × 50 × 30 mm 估計） |
| 底座 | 300 × 160 mm，總重約 3.5 kg（鋼件約 3.27 kg） |
| 穩定性 | 掛 1.5 kg 電扇時，重心離左側腳墊還有 73 mm；要在電扇中心橫推約 16 N 才會翻倒 |

座標：X 向右（電扇在左、捲線器在右），Y 往後（手機面向使用者），Z 往上，桌面 Z = 0。

## 組裝順序

1. 腳墊黏在配重板（A2）底面；底座（A1）蓋在配重板上，用 4 支 M5 沉頭螺絲鎖起來。
2. 立柱座（A3）、電扇支架（A4）用 M5 × 10 鎖進配重板的牙；捲線器（B9）用 M4 沉頭螺絲鎖上。
3. 電扇墊塊（B8）埋好熱熔螺母，從下方貼住支架頂板，用 M4 螺絲鎖好（頂面 4 支、立面 2 支）。
4. 外管底塞（B1）塞進外管底部，外管放進立柱座，用 2 支 M5 × 35 對穿鎖緊。
5. 套環（B2）放入 M6 螺帽後套上外管頂端，鎖上升降旋鈕；內管從上方插入。
6. 叉座（B3）套在內管頂端，用 M4 × 30 對穿固定。
7. 托架（B5）裝上 2 支 Ø2 銷和拉簧，插入左右夾爪（B6/B7），再勾好彈簧。
8. 轉軸（B4）埋 M6 熱熔螺母，托架用 M6 沉頭螺絲加橡膠墊片鎖在轉軸上（鎖到可以用手轉動但不會自己轉）。
9. 轉軸放進叉座雙耳之間，穿 M6 × 45 螺絲加墊片，再鎖上仰角旋鈕。

## 檢查結果

- `checks/interference.py`：在高度 0 / 80、仰角 0 / 35 / 70°、旋轉 0 / ±90°、夾爪 60 / 95 mm 的 48 種組合下，所有零件互相干涉都小於 1 mm³。**結果：通過。**
- `checks/specs.py`：內管最高時仍插入 39.5 mm；叉座最低時離套環 2.5 mm；所有列印件都放得進 A1 平台；重心和翻倒力如上表。**結果：通過。**

## 假設與限制

- 電扇的重量假設是 1.5 kg，重心在夾具外側 15 mm；電扇本體在模型中只是參考外形（半透明）。
- 充電頭尺寸是假設的 65 W GaN（約 50 × 50 × 30 mm）。如果你的充電頭比較大，改 `src/lib/dims.py` 裡的 `CHARGER_IN` 再重建就好。
- USB-C 停靠口是 8.8 × 3.0 mm 的假插座，靠摩擦力卡住插頭，不同品牌的線鬆緊會有差異，建議先印一個試試看。
- 手機橫放時，如果和電扇在同一個方向會比較靠近，必要時把電扇轉一個角度。
- 鈑金件的 3D 已經包含折彎 R 角；展開圖（DXF）和工程圖還沒做，需要的話可以接著出。

## 重建

```bash
export PYTHONPATH=src
for f in src/metal/*.py src/printed/*.py src/phone_stand.py src/phone_stand_exploded.py; do python $f; done
python checks/interference.py && python checks/specs.py
```

這裡的 `python` 是 `uvx --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python`。
