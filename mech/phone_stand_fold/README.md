# 折疊式手機支架（出廠組裝完成，打開盒子就能用）

客人拿出來，扳起手機臂、放上手機，把 DIKE DUF201 夾式風扇從上往下夾在左側的直立板上就能使用，不用任何工具，也不用自己組裝。

| 項目 | 規格 |
| --- | --- |
| 收折尺寸 | 253 × 140 × 86 mm（含風扇夾板）→ 盒子內尺寸約 263 × 150 × 96 mm |
| 重量 | 約 1.0 kg（底座鈑金 0.67 kg） |
| 手機 | 一般直板機，寬 60–95 mm、厚度含殼 ≤ 14 mm，彈簧夾爪自動夾緊 |
| 調整 | 3 個摩擦轉軸，**不用旋鈕**，直接扳到想要的位置。手機中心高度約 75–277 mm，仰角 0–60° 以上；肩部最大 70°，避免手機伸太前面時往前倒 |
| 直／橫 | 托架可轉 ±90° |
| 風扇夾板 | 配合 **DIKE DUF201**（彈簧夾，開口 46 mm，226 g）。底座左邊往下折、沿桌面往外 20 mm、再往上折成高 40 mm 的直立板，上緣反折壓邊。風扇夾子從上往下套：外側夾顎尖端頂到桌面，內側夾顎落進 U 形槽，風扇就是這一側的支撐；風扇頭可以 360° 轉到要吹的方向 |
| 收線 | 90 cm USB-C 線繞在橢圓線柱上（約 5 圈），上方有 USB-C 線頭停靠口，旁邊是充電頭收納槽 |
| 防滑 | 底座下方一圈 2 mm 矽膠條（U 形槽底也有） |

座標：X 向右（電扇在左、捲線器在右），Y 往後（手機面向使用者），Z 往上，桌面 Z = 0。

**列印方式**：`3MF/A1_plate_all_parts.3mf` 一盤就能印完全部列印件（PETG 約 135 g，0.2 mm 層高、牆數 3–4、填充 25–40%）。也可以用 `3MF/<零件>.3mf` 單獨重印某一件。只有托架背面旋轉凸台（Ø36）的下半圈需要少量支撐（Bambu Studio 選「自動支撐、只在平台上」即可），其他零件都不用。

### C. 標準件

| 用途 | 規格 | 數量 |
| --- | --- | --- |
| 3 個轉軸 | M5 對鎖螺絲（低頭、頭厚 3 mm）＋碟形彈簧＋PTFE 墊片，在工廠鎖到設定扭力後點膠 | 3 組 |
| 肘關節墊片 | Ø10 × 4 mm 尼龍或 POM 摩擦墊片（夾在上臂外側和下臂內側之間） | 2 |
| 托架旋轉 | M5 × 20 平頭沉頭螺絲＋M5 熱熔螺母＋Ø36 橡膠墊片 | 1 組 |
| 夾爪回位 | 拉簧，線徑 0.4、外徑 4、自由長約 12 mm；Ø2 × 18 定位銷 | 各 2 |
| 捲線器 | M4 × 8 平頭沉頭螺絲（鎖進底座的壓鉚螺母） | 4 |
| 防滑 | 2 mm 矽膠條（模切，背膠） | 1 組 |

**轉軸扭力設定**：以 230 g 手機加上 2 N 的手指點按力計算，肩部 ≥ 0.55 N·m、肘部 ≥ 0.55 N·m、頭部 ≥ 0.21 N·m。建議出廠設定為肩部和肘部 0.8 N·m、頭部 0.35 N·m，用手就能扳動，點螢幕時也不會下垂。

## 工廠組裝順序

1. 鈑金件折彎、壓鉚螺母和螺柱、烤漆；底座底面貼上矽膠條。
2. 下臂裝進底座的轉軸耳，用肩部轉軸鎖好。
3. 上臂裝進下臂，兩側各墊一片摩擦墊片，用肘部轉軸鎖好。
4. 頭座埋 M5 熱熔螺母，轉舌放進上臂前端，用頭部轉軸鎖好。
5. 托架裝上定位銷、拉簧和左右夾爪，用 M5 沉頭螺絲加橡膠墊片鎖在頭座上。
6. 捲線器鎖在底座右側。
7. 用扭力起子把 3 個轉軸調到設定扭力，點膠固定，最後折平裝盒。

## 檢查結果

- `checks/interference.py`：檢查收折狀態（夾爪彈回 60 mm），以及肩部 20 / 45 / 70°、上臂方向 −60 / −20 / 20 / 60°、仰角 0 / 30 / 60° 的所有組合，每種組合都測直放（夾爪 95 mm）和橫放（夾爪 60 mm）。轉軸穿過的零件不算干涉，其餘零件之間的干涉都必須小於 1 mm³。**結果：59 個姿勢中有 55 個通過。**沒通過的 4 個都是「肩部 20° 加上臂往下 20°」：頭座和托架會壓到底座和肩部轉軸。實際使用時，手機臂壓到這個位置就會被底座擋住，算是最低位置的自然擋點，不會發生零件互卡。收折狀態和其他所有使用姿勢都沒有干涉。
- `checks/specs.py`：
  - DUF201 夾得進直立板（板加壓邊 3.2 mm，夾口 46 mm）；內側夾顎放得進 20 mm 的 U 形槽。
  - **沒裝風扇時**，手機伸到最前面（肩部 70°、上臂水平往前），重心仍在前緣內側 14 mm，不會往前倒。
  - 所有列印件都放得進 A1 平台。

## 假設與限制

- 沒有加配重：DUF201 夾上之後，夾子頂在桌面上當左側支撐。但風扇只有 226 g，主要是防止支架往左倒。沒接風扇時，支架只靠約 1 kg 的自重和矽膠墊站著，用力扳手臂時請用另一隻手扶住底座。
- DUF201 的夾顎長度和厚度是**依照片估計的**：模型中假設夾顎長約 60 mm、厚約 12 mm，只要夾顎長度 ≥ 45 mm 就頂得到桌面。請拿實物量一下夾顎長度和最厚的那片夾顎；如果超過 16 mm，U 形槽要再加寬。
- 風扇在模型中只是參考外形（半透明，頭徑 150 mm）。
- 充電頭槽是照 65 W GaN（約 50 × 50 × 30 mm）估計的。
- USB-C 停靠口靠摩擦力卡住線頭，量產前建議用幾款常見的線實際試插。
- 鈑金件的 3D 有 R 角，但還沒做展開圖（DXF）和工程圖。

## 重建

```bash
export PYTHONPATH=src
for f in src/sheet/*.py src/printed/*.py src/phone_stand_fold*.py src/phone_stand_folded.py; do python $f; done
python checks/specs.py && python checks/interference.py && python checks/plate.py
python src/print_plate/combine_3mf.py   # 重新產生 A1 整盤 3MF
```

這裡的 `python` 是 `uvx --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python`。
