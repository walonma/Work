# 機器小鴨 3D 概念模型（Microduck 級）

參考 Pollen Robotics／Hugging Face 的 Microduck（約 25 cm、15 顆伺服），做一隻同等級的雙足機器小鴨。這個階段的目標是**空間配置**：外型比例、15 個關節的位置和方向、電池和主板的擺放、互動模組的位置。並確認在常用姿勢下零件不會互撞、重心落在兩腳之間。主控沿用 **RK3566**。

互動 3D 審圖頁：`viewer/robot_duck_viewer.html`（可以拉 15 個關節、按分類切換料件）。

## 規格（概念模型量測值）

| 項目 | 值 |
| --- | --- |
| 高度 | 258 mm（頭頂），外形 201 × 98 × 258 mm |
| 估計重量 | 476 g（不含螺絲、線材、軸承；實際做出來預估 650–800 g，見下方說明） |
| 重心 | X 17 mm、Y 0、Z 136 mm，在腳踝正上方 |
| 關節 | 15 個：每條腿 5 個、脖子和頭 4 個、嘴巴 1 個 |
| 主控 | RK3566 主板，65 × 30 mm（例如 Radxa Zero 3W 尺寸），放在電池上方，IMU 在板上 |
| 電池 | 2S 800 mAh 扁鋰電池 50 × 26 × 13 mm，放在身體最低處 |

座標：X 往前（嘴巴方向）、Y 往左、Z 往上，桌面 Z = 0，零點姿勢是雙腿打直站立。

## 關節配置

| 關節 | 伺服等級 | 活動範圍 |
| --- | --- | --- |
| 左右髖部轉向 | XL330 / HD-1910 級（34 × 20 × 26，約 18 g） | ±30° |
| 左右髖部側擺 | 同上 | ±20° |
| 左右髖部前後 | 同上 | ±60° |
| 左右膝 | 同上 | −10 ~ 90° |
| 左右踝 | 同上 | ±45° |
| 脖子俯仰 | 同上 | −30 ~ 25° |
| 頭部轉向 | SCS0009 級微型（23 × 12 × 24，約 9 g） | ±90° |
| 頭部俯仰 | 同上 | ±12° |
| 頭部側歪 | 同上 | ±15° |
| 嘴巴開合 | 同上 | −5 ~ 35° |

點頭主要靠脖子俯仰，頭部的俯仰和側歪只做小幅度表情動作：4 顆微型伺服塞在直徑 68 mm 的頭裡，空間只夠這樣的角度。

## 料件（模型中 67 件）

| 類別 | 模型件數 | 估計重量 | 內容 |
| --- | --- | --- | --- |
| 伺服與舵盤 | 30 | 241 g | 15 顆伺服＋15 個舵盤 |
| 結構件 | 13 | 40 g | 骨盆骨架、髖部轉向支架 × 2、髖部支架 × 2、大腿 × 2、小腿 × 2、脖子連桿、頭部俯仰／側歪支架、頭部骨架 |
| 外殼與外觀件 | 16 | 113 g | 身體上下殼、頭殼前後、翅膀 × 2、尾巴、頸套、上下嘴喙、眼睛透明罩 × 2、腳掌 × 2、腳底防滑墊 × 2 |
| 電子模組 | 8 | 82 g | RK3566 主板、電池、喇叭、ToF、相機、麥克風、眼睛圓形 LCD × 2 |

模型裡還沒畫、量產 BOM 要加上的東西：
- **軸承：** 每個腿關節在舵盤對面加一顆，約 10–12 顆。
- **線材：** 伺服菊鍊線約 16 條，加上相機和 LCD 的排線。
- **扣件：** 螺絲和熱熔螺母約 120–150 顆。
- **電源件：** 電源開關、USB-C 充電口、電池保護板。

加上這些以後，總件數大約 250 件、60–70 個料號。

## 檢查結果

- `checks/interference.py`：站立、蹲下、看左邊、往右下看、張嘴叫、跨步、趴睡共 7 個姿勢，所有零件兩兩之間的干涉都小於 1 mm³。**結果：通過。**
- `checks/mass.py`：重量 ≤ 800 g、重心在腳掌範圍內且左右置中、高度約 25 cm。**結果：通過。**

## 概念模型的限制

- 伺服是外形佔位，尺寸取自 XL330 和 Feetech SCS0009 級。正式選型後要更新 `src/lib/dims.py` 的 `LEG_SERVO`、`MICRO_SERVO` 再重建。
- 結構件是最簡化的板件，還沒有肉厚、補強、螺絲孔和軸承座，所以重量偏輕。
- 腿目前是裸露的伺服疊，還沒有腿套等外觀件。脖子伺服的上半部也露在身體外面，下一版要設計可以跟著轉的頸部外殼。
- 走路沒有做動力學模擬；這裡只確認了靜態站立時的重心位置。

## 建議下一步

1. 選定伺服型號，用實際扭力檢查單腳支撐時的膝和踝。
2. 結構件細化：雙邊軸承支撐、螺絲和卡扣、防撞軟膠、走線路徑。
3. 輸出 URDF/MJCF，把正確的質量和慣量帶進 Isaac Lab 或 MuJoCo，訓練走路。
4. 外觀件：腿套、頸部外殼、眼睛和嘴巴的表情設計。

## 檔案與重建

| 檔案 | 內容 |
| --- | --- |
| `STEP/robot_duck.step` | 總組立，含 15 個關節的運動定義和預設姿勢（在 CAD Viewer 可以拖拉） |
| `GLB/robot_duck.glb` | 網頁／手機預覽用 |

| `src/lib/parts.py`、`src/lib/assembly_tree.py` | 零件和運動樹 |

```bash
export PYTHONPATH=src
python src/robot_duck.py                     # STEP + GLB
python checks/interference.py && python checks/mass.py
python src/tools/export_viewer.py && python3 src/tools/build_viewer.py   # 審圖網頁
```

這裡的 `python` 是 `uvx --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python`。
